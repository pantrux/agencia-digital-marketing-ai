# Fase 5 · Equipo OpenClaw y servidores MCP

Los cinco agentes de la agencia ya figuran en el gateway de `192.168.0.7:18789`. La lectura autenticada acreditó disponibilidad del gateway y de los dos modelos requeridos. La entrega agrega las skills y los cuatro MCP, y comprueba la invocación de cada agente y de cada servidor con material sintético o propio. [Plan de implementación](../PLAN-DE-IMPLEMENTACION.md#fase-5-equipo-de-5-agentes-agency--skills-con-urls-exactas-y-4-mcps-en-19216807) · [Arquitectura, asignación por agente](../ARQUITECTURA-PLATAFORMA-AUDIOVISUAL.md#41-asignación-de-modelos-roles-y-mcps-por-agente)

## Trabajo y aceptación

| Entrega | Prueba |
| --- | --- |
| Contratos y transporte MCP por stdio | Inicialización, catálogo y llamada por el SDK o un cliente MCP fijado. Los errores de transporte y de servicio se distinguen en el recibo. Las claves salen de archivos protegidos del servicio. |
| Inspector de medios | La fixture MP4 produce metadatos, medición ebur128 y tira graduada de 0 a 1920 px. Whisper entrega palabras con tiempos monótonos. Las referencias de media permanecen dentro del proyecto. |
| Immich B-roll | Una consulta CLIP devuelve el ID esperado de una fixture propia, indexada y visible para la cuenta. La clave queda acotada a lectura. |
| Remotion GPU | El MCP devuelve una imagen de revisión y el MP4 maestro con hashes, dimensiones, códec y audio cotejados. Las restricciones de plan usan el contrato del renderer. |
| Kitsu Review | En un proyecto propio, el bot obtiene los IDs de una entrega, sube dos versiones de la fixture y lee la anotación de un fotograma de la segunda versión. La prueba acredita los permisos por operación. |
| Skills | Se prepara una lista fijada de archivos y huellas para las seis fuentes externas y las dos locales. Se incorporan además las tres skills internas del plan. Cada workspace recibe sus skills y sus referencias necesarias. |
| Reconciliación de los agentes | Comparar configuración anterior y posterior, modelos, workspaces, skills y permisos. Un dry-run debe preservar las 14 entradas ajenas y el MCP preexistente. Probar que un agente ajeno no recibe las herramientas de la agencia. |
| Invocaciones reales | Ejecutar una llamada acotada por rol con el modelo exacto y comprobar una llamada positiva por MCP. Mantener registro de quién invocó la herramienta y de los IDs o hashes que devuelve, sin contenido privado. |

Los cuatro adaptadores usan MCP por stdio. El plugin de la agencia recibe el ID del agente de OpenClaw y comprueba el rol antes de crear la herramienta. La configuración añade permisos explícitos sólo a los cinco agentes. La preparación deja intacto el registro compartido `mcp.servers`. El runtime de Python se fija por ruta absoluta en la configuración del plugin porque OpenClaw carga su módulo desde un artefacto capturado. [Tipos del plugin de OpenClaw 2026.10.10](https://github.com/openclaw/openclaw/blob/v2026.10.10/src/plugins/tool-types.ts) · [Cargador](https://github.com/openclaw/openclaw/blob/v2026.10.10/src/plugins/plugin-native-module-loader.ts#L243-L251) · [Política de herramientas](https://github.com/openclaw/openclaw/blob/v2026.10.10/docs/gateway/config-tools/tool-policy.md)

El plan conserva las seis referencias designadas. Remotion cambió la ruta interna de su archivo principal. Los dueños de RunComfy e Inference.sh redirigen las referencias históricas y se cotejan los IDs concretos. La instalación usa el contenido fijado por HTTPS, dado que el CLI de adquisición remota puede invocar Git. Los proveedores externos de generación conservan sus propios requisitos de credenciales. [Proveedor RunComfy](https://github.com/prime-skills/runcomfy-agent-skills/blob/main/ai-image-generation/SKILL.md) · [Proveedor Inference.sh](https://github.com/inference-sh/skills/blob/main/tools/video/ai-video-generation/SKILL.md) · [Fallback del instalador](https://github.com/vercel-labs/skills/blob/main/src/blob.ts)

- El instalador cotejó 508 archivos para 27 asignaciones de skills en cinco workspaces. La segunda aplicación en el fixture encontró todos los archivos idénticos y conservó la configuración del agente y MCP ajenos. Pasó una invocación permitida y rechazó tanto el acceso del agente ajeno como la solicitud de máster del rol de crítica. Este ensayo usó sesiones vacías y un cliente de prueba. [Ensayo de permisos](../../.tools/evidence/phase5-openclaw-tool-access-isolated-20261114-v2.json)

Con idioma inglés forzado el mismo audio devolvió 26 palabras y tiempos monótonos.
